# Rain VFX Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Configure the existing `RainEffect` ParticleSystem to look like real rain, and make storm rain heavier than normal rain.

**Architecture:** `WeatherOverlay` already subscribes to `WeatherService.OnWeatherUpdated` and calls `rainEffect.Play()` for Rain/Storm. Task 1 tunes the particle system properties via Unity MCP. Task 2 adds dynamic emission rate switching in `WeatherOverlay.cs` so storm is visibly heavier than rain.

**Tech Stack:** Unity 6 ParticleSystem, Unity MCP `manage_vfx`, C# `ParticleSystem.EmissionModule`

---

### Task 1: Configure RainEffect particle system

**Files:**
- Modify (scene): `WeatherOverlay/RainEffect` GameObject via MCP

No unit test possible for particle visuals — verification is a play-mode screenshot.

**Step 1: Set simulation space to World**

```
manage_vfx action=particle_configure
  target=RainEffect
  properties={ simulationSpace: "World" }
```

**Step 2: Set emission rate, max particles, lifetime, speed, gravity**

```
manage_vfx action=particle_configure
  target=RainEffect
  properties={
    rateOverTime: 300,
    maxParticles: 600,
    startLifetime: 0.8,
    startSpeed: 25,
    gravityModifier: 2.5
  }
```

**Step 3: Set render mode to Stretch**

```
manage_vfx action=particle_configure
  target=RainEffect
  properties={
    renderMode: "Stretch",
    lengthScale: 4
  }
```

**Step 4: Set start color (translucent blue)**

```
manage_vfx action=particle_configure
  target=RainEffect
  properties={
    startColor: [180, 210, 240, 115]   # rgba, 115 ≈ 0.45 alpha
  }
```

**Step 5: Set shape to wide Box emitter above screen**

```
manage_vfx action=particle_configure
  target=RainEffect
  properties={
    shapeType: "Box",
    shapeScaleX: 20,
    shapeScaleY: 1,
    shapeScaleZ: 1
  }
```
Move `RainEffect` transform to position (0, 10, 0) so particles spawn above the visible area.

**Step 6: Set sorting layer above LivingCanvas**

Set `sortingOrder` on the renderer to 10 (LivingCanvas renders at 0 in Default layer).

**Step 7: Enter play mode and screenshot to verify rain falls**

Expected: translucent blue streaks falling from top of screen.

**Step 8: Save scene + commit**

```bash
git add Assets/Scenes/SampleScene.unity
git commit -m "feat: configure RainEffect particle system for realistic rain"
```

### Task 2: Dynamic emission for Storm vs Rain

**Files:**
- Modify: `Assets/Scripts/UI/WeatherOverlay.cs`

Storm should emit 2× more particles than regular rain to feel heavier.

**Step 1: Update `UpdateEffects` to set emission rate before playing**

Replace the Rain/Storm case in `WeatherOverlay.cs`:

```csharp
case WeatherCondition.Rain:
case WeatherCondition.Storm:
    if (rainEffect != null)
    {
        var emission = rainEffect.emission;
        emission.rateOverTime = w.condition == WeatherCondition.Storm ? 600f : 300f;
        rainEffect.Play();
    }
    if (w.condition == WeatherCondition.Storm && windLines != null)
        windLines.Play();
    break;
```

**Step 2: Enter play mode, use Debug panel to switch between Rain and Storm**

- Set condition to Rain → moderate streaks
- Set condition to Storm → noticeably heavier, denser rain

**Step 3: Commit**

```bash
git add Assets/Scripts/UI/WeatherOverlay.cs
git commit -m "feat: differentiate storm vs rain emission rate (600 vs 300/sec)"
```
